# Visual component attribution

## React Bits

NPrep's `src/components/react-bits/spotlight-card.tsx` and `count-up.tsx` are reduced, adapted versions of React Bits' SpotlightCard and CountUp. They retain pointer-position lighting and Motion-based numeric interpolation, with NPrep styling, a smaller API, static accessible values, and reduced-motion behavior.
